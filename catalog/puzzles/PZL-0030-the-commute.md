Three commuters — Dara, Ellis, and Fen — each get to work using one or more of three modes:
bus, train, and bicycle.

1. Ellis uses the bicycle, and nothing else.
2. Fen uses the train and the bicycle.
3. Dara uses the bus or the train.
4. Dara does not use the bicycle.
5. Counting each person's modes separately, exactly five modes are used in total.

Which modes does Dara use?

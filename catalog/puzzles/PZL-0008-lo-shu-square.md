Fill a 3-by-3 grid with each of the digits 1 through 9, using each digit exactly once, so that
every row, every column, and both diagonals add up to the same total: 15.

The top-left cell is 4. The top-middle cell is 9. The center cell is 5.

What number goes in each of the remaining six cells?
